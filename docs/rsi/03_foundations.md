# 03｜理论、元学习与开放式学习

[返回总览](README.md) · 本章收录 P01–P07、P57。

本章提供三类根基：Good 与 Gödel Machine 讨论为什么以及在什么条件下可以自我改进；元学习与 NAS 说明“学习过程/设计过程”也能成为优化对象；AlphaZero、POET 与 AI-GAs 说明数据和任务未必需要始终由人类提供。

<a id="p01"></a>
## P01｜Speculations Concerning the First Ultraintelligent Machine

**文献**：I. J. Good；历史上常引作 1965，当前出版社记录为 1966；*Advances in Computers*, Vol. 6, pp. 31–88。[出版社原文](https://www.sciencedirect.com/science/article/pii/S0065245808604180)。

**问题与思路**：如果机器超过人类的广泛智力，设计机器本身也属于其能力范围，因此它可能设计更好的后继者。这构成“智能爆炸”论证的经典起点。

**贡献与证据边界**：它提供概念性反馈链，不提供可执行算法、收敛证明或速度预测。机器设计能力、实验成本、验证难度和资源获取都会影响反馈强度；不能从该论证直接推出改进必然失控或呈指数增长。

**连接**：向下接 [P02](#p02) 的形式化自修改；向现代系统接 [P36](08_automated_science.md#p36) 的自动研究与 [P51](10_frontier.md#p51) 的元层优化。这里是思想关联，不是算法继承。

**研究启发**：把“智能”拆成可测的研究子能力，例如提出有效实验、识别失败原因、减少试验成本，而不是只讨论总能力曲线。

<a id="p02"></a>
## P02｜Gödel Machines: Self-Referential Universal Problem Solvers Making Provably Optimal Self-Improvements

**文献**：Jürgen Schmidhuber，2003 技术报告/arXiv；后续存在 2007 年章节版本，标题略有不同。[2003 原文](https://arxiv.org/abs/cs/0309048) · [作者正文](https://people.idsia.ch/~juergen/gmweb3/gmweb3.html)。

**问题与方法**：系统如何修改自身而仍有理由相信修改有益？初始系统包含求解程序、证明搜索器及描述硬件、程序、环境假设和效用的公理。当搜索到证明，表明现在执行某次改写比继续既定搜索更有益时，允许切换；证明搜索器本身也可以是改写对象。

**贡献**：自我指涉与可修改元层被纳入一个统一形式系统。所谓最优性依赖可证明的切换条件及公理，而不是声称任何实际程序都能快速找到全局最优修改。

**局限**：有益修改可能无法在所用公理系统中证明，证明搜索可能过于昂贵，真实任务效用也很难完整形式化。这是理论参照，不是已部署的通用 RSI。

**连接**：[P01](#p01) 的思想获得形式化；[P31 Gödel Agent](07_recursive_agents.md#p31) 借用自指思想，[P33 DGM](07_recursive_agents.md#p33) 转向经验检验。两者都不因此继承原定理的保证。

**研究启发**：把证明局限在类型、接口、不变式等可验证部分，把收益交给独立实证评估，研究混合验证成本与可靠性的关系。

<a id="p03"></a>
## P03｜Learning to learn by gradient descent by gradient descent

**文献**：Marcin Andrychowicz 等，2016。[原文](https://arxiv.org/abs/1606.04474)。

**问题与方法**：优化器为何必须手工设计？用 LSTM 根据梯度和内部状态产生参数更新，通过展开被优化模型的训练过程学习优化器参数。内层优化目标模型，外层优化“怎样更新目标模型”。

**证据**：在作者研究的优化任务与结构相近的新任务上，学得的优化器可优于部分手工优化器。它使“学习规则可学习”成为直接实验对象。

**局限**：外层训练框架、任务分布与元目标仍由人设计；有限展开长度还会限制长训练迁移。学得一个优化器与优化器自主改写自身并不相同。

**连接**：与 [P04](#p04) 对照：前者学更新规则，后者学好初始化；与 [P29 STOP](07_recursive_agents.md#p29) 连接：连续参数优化器变成代码表达的改进器。

**研究启发**：比较一个修改对当前任务的直接收益与对未来学习速度的收益，两者可以方向不同。

<a id="p04"></a>
## P04｜Model-Agnostic Meta-Learning for Fast Adaptation of Deep Networks

**文献**：Chelsea Finn、Pieter Abbeel、Sergey Levine，ICML 2017。[会议原文](https://proceedings.mlr.press/v70/finn17a.html)。

**问题与方法**：怎样让模型用少量新数据快速适应？在多个训练任务上，先模拟少量梯度更新，再优化更新后的表现，得到容易微调的初始参数。

**证据**：论文覆盖少样本分类、回归与强化学习；关键是把“适应之后的性能”作为训练目标，而非只让当前模型得高分。

**局限**：适应步骤、外层算法和任务分布仍固定，因此属于元学习基础，不是完整 RSI。跨分布、跨训练长度或跨模型规模的泛化需要另测。

**连接**：承接 [P03](#p03) 的双层优化视角；可用于理解 [P51](10_frontier.md#p51) 为何需要比较“生成后代之后”的性能，但不能说 Hyperagents 使用了 MAML。

**研究启发**：设计 RSI 评价时，把后续适应效果纳入目标，避免以当前最高任务分数选出最不善于继续改进的父代。

<a id="p05"></a>
## P05｜Neural Architecture Search with Reinforcement Learning

**文献**：Barret Zoph、Quoc V. Le，2016 首稿。[原文](https://arxiv.org/abs/1611.01578)。

**问题与方法**：以循环网络作为控制器，生成神经网络结构；训练候选结构，用验证集表现作为奖励来更新控制器。结构设计从人工经验转为外层搜索。

**证据**：在图像分类和语言建模实验中发现有竞争力的结构。意义在于明确“设计表示—候选生成—训练—评价”这一自动设计流程。

**局限**：候选训练成本大，搜索空间与训练器仍预设；在结构空间内发现更优网络，不等于搜索器也获得改进。

**连接**：[P30 ADAS](07_recursive_agents.md#p30) 将类似自动设计问题搬到智能体代码空间；[P38 AFlow](07_recursive_agents.md#p38) 针对工作流结构；[P57](#p57) 将结构搜索列为 AI 生成系统的一部分。

**研究启发**：系统级 RSI 研究仍须报告搜索空间和总搜索成本，不能只比较最终产物的推理成本。

<a id="p06"></a>
## P06｜AlphaZero

**文献**：David Silver 等，2017 首稿 *Mastering Chess and Shogi by Self-Play with a General Reinforcement Learning Algorithm*。[原文](https://arxiv.org/abs/1712.01815)。后续 Science 版本有不同标题，本文采用该首稿作为引用版本。

**问题与方法**：不依赖人类棋谱，结合自博弈、策略/价值网络与蒙特卡洛树搜索产生训练目标。更好的网络改善搜索与对局分布，新的对局再训练网络。

**证据**：在明确规则的棋类环境中达到极强性能，说明外部精确反馈与有效搜索可以支持超越示范者的学习。

**局限**：环境规则、奖励、搜索算法、网络训练框架是人工给定的。它证明的是特定闭环可以成功，不是所有自然语言任务都能照搬胜负式自博弈。

**连接**：[P12 SPIN](04_self_training.md#p12) 也使用 self-play 名称，但人类示范仍是目标锚点；[P18 Absolute Zero](05_curricula.md#p18) 用可执行任务提供环境反馈；[P19 R-Zero](05_curricula.md#p19) 则需处理伪标签问题。

**研究启发**：优先寻找“生成候选很难、检查候选相对便宜”的领域，但须评估检查器的覆盖范围。

<a id="p07"></a>
## P07｜Paired Open-Ended Trailblazer（POET）

**文献**：Rui Wang、Joel Lehman、Jeff Clune、Kenneth O. Stanley，2019；完整标题见索引。[原文](https://arxiv.org/abs/1901.01753)。

**问题与方法**：如果训练任务固定，能力发展可能受课程限制。POET 同时维护环境与求解器，产生新的环境、优化对应策略，并尝试在环境之间迁移解。

**证据**：在论文的模拟控制环境中，跨环境“踏脚石”帮助抵达直接优化或简单课程难以找到的能力。这支撑保留多样路径的价值。

**局限**：环境表示、变异和优化过程依然受设计约束；开放式生成机制不等于实验已经证明可无限增长。

**连接**：为 [P18–P20](05_curricula.md) 的课程与求解器共同演化提供概念背景；与 [P33 DGM](07_recursive_agents.md#p33) 的多分支档案连接，保留当下不是最优的候选可能有长期价值。

**研究启发**：需要消融“只保留当前最优”与“保留行为多样性”，并区分真正踏脚石收益和额外采样收益。

<a id="p57"></a>
## P57｜AI-GAs: AI-generating algorithms, an alternate paradigm for producing general artificial intelligence

**文献**：Jeff Clune，2019 首稿，2020 修订；研究议程/观点论文。[原文](https://arxiv.org/abs/1905.10985)。

**问题与框架**：与逐个手工设计智能模块相比，能否设计产生智能系统的算法？论文提出三个支柱：学习架构、学习学习算法、生成有效学习环境。

**贡献与边界**：它提供整体研究路线，不是一个已经实现通用智能的系统，也不是三个支柱组合必然成功的定理。

**连接**：三个支柱分别对应 [P05 NAS](#p05)、[P03 学习优化器](#p03)、[P07 POET](#p07)；现代对应物可以是 [P30 ADAS](07_recursive_agents.md#p30)、[P51 Hyperagents](10_frontier.md#p51)、[P18 Absolute Zero](05_curricula.md#p18)。这些对应是本笔记的综合映射。

**研究启发**：选题不必从全自动系统开始；可先固定两个支柱，仅让第三个演化，再检查它是否带来可迁移、可归因的收益。
