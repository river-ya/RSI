# 04｜自生成数据、自反馈与参数更新

[返回总览](README.md) · 本章收录 P08–P16、P39、P60。

这条路线逐步把人工提供的东西交给模型：先生成指令，再生成推理，再生成偏好，最后训练评价器本身。但每一步都要回答“为什么这些自生成信号值得学习”。更新仍主要由人设计的训练程序完成，因此不能把所有自训练统称为严格 RSI。

<a id="p08"></a>
## P08｜Self-Instruct: Aligning Language Models with Self-Generated Instructions

**文献**：Yizhong Wang 等，2022 首稿，ACL 2023。[原文](https://arxiv.org/abs/2212.10560)。

**问题**：人工指令数据的数量、覆盖面和编写成本限制指令微调。

**方法**：从少量种子任务出发，让语言模型生成指令、输入与输出，过滤无效或过度相似的样本，再用这些数据微调原模型。它把模型潜在的任务知识整理成训练集。

**证据**：作者在指令泛化与人工评估中观察到明显收益。核心结论是自生成数据能帮助指令对齐，而非模型已经自动创造可靠的新知识。

**边界**：过滤器和种子决定覆盖面；生成答案不一定正确；同源错误可能被强化。数据生成闭环与改进器自修改是两个层次。

**连接**：与 [P09 STaR](#p09) 分别解决“生成任务”和“生成推理”；通向 [P18 Absolute Zero](05_curricula.md#p18) 的任务自生成，但后者增加可执行反馈和动态课程。

**可研究点**：按语义难度与错误类型衡量合成数据多样性，比较更多样本与更好筛选哪个更有价值。

<a id="p09"></a>
## P09｜STaR: Bootstrapping Reasoning With Reasoning

**文献**：Eric Zelikman、Yuhuai Wu、Jesse Mu、Noah D. Goodman，2022；会议标题亦使用 *Self-Taught Reasoner*。[原文](https://arxiv.org/abs/2203.14465)。

**问题**：只有少量带推理过程的示例时，如何扩大可训练的推理轨迹？

**方法**：生成推理与答案；保留答案正确的轨迹；对于失败样本，将正确答案提供给模型以尝试生成合理解释；在成功轨迹上微调，再重复采样。

**证据与意义**：论文说明答案级监督可转化为更多推理训练样本。自生成轨迹并非全部都有价值，筛选步骤是闭环核心。

**边界**：依赖已知正确答案；正确终点不保证每一步推理有效；基于答案的合理化可能学到事后解释。循环更新参数，没有自主改写训练算法。

**连接**：向 [P11 ReST-EM](#p11) 接“采样—筛选—拟合”；向 [P14 Quiet-STaR](#p14) 接一般文本中的隐式推理；与 [P43 过程监督](09_evaluation.md#p43) 对照终点正确与过程正确。

**可研究点**：在答案正确但推理错误的样本上做定向评估，研究过程验证能否改善长期自训练。

<a id="p10"></a>
## P10｜Reinforced Self-Training（ReST）for Language Modeling

**文献**：Caglar Gulcehre 等，2023。[原文](https://arxiv.org/abs/2308.08998)。

**问题**：在线偏好强化学习昂贵，能否复用模型生成的数据？

**方法**：由当前策略生成候选，依据奖励筛选或加权，再离线改进策略；交替进行生成数据与改进模型的步骤。论文主要在机器翻译中研究效率与质量。

**证据**：自动指标和人工评价支持其在所研究翻译设置中的提升；数据复用为成本控制提供了实用路径。

**边界**：奖励模型不会因反复优化自动变成可靠真值；多次复用也可能放大偏差。论文不能直接支持数学推理、代码和任意智能体任务上的同等效果。

**连接**：由 [P09](#p09) 的筛选式学习理解其直觉；[P11](#p11) 将该思路用于有可验证反馈的问题求解；[P48](09_evaluation.md#p48) 揭示反复优化代理奖励的风险。

**可研究点**：以相同总采样和评价预算比较频繁刷新数据与重复训练旧数据。

<a id="p11"></a>
## P11｜Beyond Human Data: Scaling Self-Training for Problem-Solving with Language Models（ReST-EM）

**文献**：Avi Singh、John D. Co-Reyes、Rishabh Agarwal 等，2023 首稿。[原文](https://arxiv.org/abs/2312.06585)。

**问题与方法**：在数学和代码任务中，利用二值反馈筛选模型生成的解，再监督微调，并重复数轮。论文以期望最大化视角解释这一简单闭环。

**证据**：基于 PaLM-2 在 MATH 与 APPS 上的实验显示，自训练可超过仅用人类解答微调的基线，并具有模型规模相关的收益。

**边界**：人工题目或任务分布及验证信号仍然存在；不是完全不依赖人类数据。若初始模型几乎无法采样到正确解，筛选不会凭空产生训练信号。

**连接**：承接 [P10 ReST](#p10)，与 [P09 STaR](#p09) 共享成功轨迹学习思想；通向 [P17 R1](05_curricula.md#p17) 的可验证奖励训练，也构成 [P18](05_curricula.md#p18) 去除人工题目后的重要对照。

**可研究点**：在固定验证次数下，比较增加候选数、提高验证器准确率和生成新任务的边际收益。

<a id="p12"></a>
## P12｜Self-Play Fine-Tuning Converts Weak Language Models to Strong Language Models（SPIN）

**文献**：Zixiang Chen、Yihe Deng、Huizhuo Yuan、Kaixuan Ji、Quanquan Gu，2024。[原文](https://arxiv.org/abs/2401.01335)。

**问题与方法**：已有 SFT 数据能否被更充分利用，而不再添加人工标注？模型生成回答，将其与现有人工示范对照，采用偏好式目标迭代更新；上一轮策略为下一轮提供可区分的对手分布。

**证据**：作者报告多个语言与对话评估上的提升，并分析理想化目标下与目标数据分布匹配的性质。

**边界**：没有新增人工标注不等于没有人工监督；人类示范仍是锚点。理论性质不是真实大模型有限样本训练一定收敛或超过人类的保证。

**连接**：用 [P15 DPO](#p15) 理解偏好损失；与 [P06 AlphaZero](03_foundations.md#p06) 区分两种 self-play；与 [P13](#p13) 区分“人工示范对照”与“模型自产奖励”。

**可研究点**：分析模型已接近示范质量时，继续把所有自生成回答视作较差答案是否会限制改进。

<a id="p13"></a>
## P13｜Self-Rewarding Language Models

**文献**：Weizhe Yuan 等，2024。[原文](https://arxiv.org/abs/2401.10020)。

**问题**：固定奖励模型可能成为迭代对齐的瓶颈，能否让回答能力与评价能力共同进步？

**方法**：同一语言模型承担回答者与 LLM-as-a-Judge 两种角色，生成候选、评价候选、构造偏好对，再通过迭代 DPO 训练。

**证据**：论文在有限轮次中报告指令遵循与评价质量的共同提升；支持研究联合自举，而不是证明内部一致性一定等于真实质量。

**边界**：同源回答者与裁判可能共享盲点；风格、篇幅偏好会反馈进训练。初始指令和评价数据等条件仍须计入监督来源，不能称为从零创造标准。

**连接**：由 [P16 Constitutional AI](#p16) 的 AI 反馈、[P15 DPO](#p15) 的优化目标相接；[P60](#p60) 单独研究评价器自举；[P44](09_evaluation.md#p44) 与 [P48](09_evaluation.md#p48) 提供偏差对照。

**可研究点**：同时演化回答者和裁判时，冻结第三方审计器，分离评价质量提升、偏好漂移和回答质量提升。

<a id="p14"></a>
## P14｜Quiet-STaR: Language Models Can Teach Themselves to Think Before Speaking

**文献**：Eric Zelikman 等，2024。[原文](https://arxiv.org/abs/2403.09629)。

**问题与方法**：STaR 依赖问答任务和答案正确性，能否利用一般文本学习隐式推理？模型在文本位置生成潜在思考，根据这些思考是否帮助预测后续文本来学习；配合并行采样与思考边界标记控制计算。

**证据**：作者在继续预训练和下游零样本评估中报告收益，表明思考训练可利用非显式推理语料。

**边界**：语言预测改善与事实正确性、可解释性不等价；需要计算开销，也不是推理机制代码自我改写。不能把模型生成的思考直接当作忠实内部解释。

**连接**：是 [P09 STaR](#p09) 的明确扩展；与 [P39 Toolformer](#p39) 都可从后续 token 预测收益中筛选有用中间步骤，但前者是思考，后者是工具调用。

**可研究点**：比较“有助于预测的思考”与“通过外部检验的推理”对跨任务迁移的不同影响。

<a id="p15"></a>
## P15｜Direct Preference Optimization: Your Language Model is Secretly a Reward Model

**文献**：Rafael Rafailov 等，2023 首稿。[原文](https://arxiv.org/abs/2305.18290)。

**问题与方法**：传统 RLHF 将奖励拟合与策略优化分开，训练链较复杂。DPO 利用特定偏好模型和 KL 正则目标之间的关系，把策略更新化为偏好对上的分类式损失，省去单独的在线 RL 阶段。

**证据**：论文在情感控制、摘要和对话上展示较简洁的偏好优化方案。它提供的是训练工具，不自动产生偏好或验证标准。

**边界**：可靠性仍依赖偏好数据与参考策略；“没有显式奖励模型”不等于没有代理目标误差或过优化。

**连接**：支撑 [P12 SPIN](#p12) 与 [P13 Self-Rewarding](#p13) 的阅读；与 [P48](09_evaluation.md#p48) 共同理解“优化过程”和“质量信号”必须分别讨论。

**可研究点**：固定训练算法后只改变自生成偏好质量，可更清楚地测量评价器对闭环收益的贡献。

<a id="p16"></a>
## P16｜Constitutional AI: Harmlessness from AI Feedback

**文献**：Yuntao Bai 等，2022。[原文](https://arxiv.org/abs/2212.08073)。

**问题与方法**：能否用原则列表减少逐条人工无害性标注？先让模型依据原则批评和修订回答，监督学习修订结果；再生成 AI 偏好，训练偏好模型并进行强化学习。

**证据**：论文研究有帮助且较少有害的助手训练，说明文本化规范可以参与规模化反馈。

**边界**：无害性标注减少不代表整个训练过程没有人工信号；原则、初始模型和其他训练阶段仍有外部设计。规范一致性也不保证数学或代码正确性。

**连接**：将 [P22 Self-Refine](06_scaffolds.md#p22) 式批评修订与参数更新作概念对照；为 [P13](#p13) 提供 AI 反馈背景；与 [P52 GAI](10_frontier.md#p52) 讨论目标是否保持外部锚定相连。

**可研究点**：让策略可变而保留可审计的目标规范，检查多轮改进是否逐渐偏离初始目标。

<a id="p39"></a>
## P39｜Toolformer: Language Models Can Teach Themselves to Use Tools

**文献**：Timo Schick 等，2023。[原文](https://arxiv.org/abs/2302.04761)。

**问题与方法**：模型如何学习什么时候调用工具？给定少量 API 示例，生成可能的调用位置与参数，执行工具，并保留有助于后续语言预测的调用，再据此训练。

**证据**：计算器、检索等工具改善多个下游任务，说明工具使用轨迹可部分自动构造。

**边界**：工具 API 与候选生成规则预先给定，模型学习调用而不是自主发明整个工具系统；局部预测收益也不充分覆盖长程任务收益。

**连接**：与 [P14](#p14) 共享中间步骤自监督思想；[P21 ReAct](06_scaffolds.md#p21) 强调推理时交互；[P24 Voyager](06_scaffolds.md#p24) 进一步积累可执行技能；[P20 Agent0](05_curricula.md#p20) 把工具带入自课程。

**可研究点**：区分“学会调用既有工具”与“创造更好的工具”，以独立任务测试工具的真实复用价值。

<a id="p60"></a>
## P60｜Self-Taught Evaluators

**文献**：Tianlu Wang 等，2024。[原文](https://arxiv.org/abs/2408.02666)。

**问题与方法**：评价器也依赖昂贵且会过时的人工偏好数据。论文从无标签指令产生有对比性的回答，训练裁判的判断理由与最终选择，再迭代改进预测和训练数据。

**证据**：作者在 RewardBench 上报告评价能力提升。它把评价器本身作为自训练对象，补上只关注生成器的一块缺口。

**边界**：已有强指令模型、指令来源和合成偏好构造仍是先验；在奖励基准上更强，不意味着面对主动利用裁判漏洞的策略仍然可靠。

**连接**：与 [P13](#p13) 的生成器/裁判共同更新相比，本篇更集中于评价器；与 [P44](09_evaluation.md#p44) 的裁判偏差、[P48](09_evaluation.md#p48) 的适应性过优化形成一组阅读。

**可研究点**：评价器更新后，旧的对抗样本是否仍能检出？新评价器有没有遗忘以前已经识别的错误？

## 横向梳理：每一步究竟少了哪类人工输入？

| 方法 | 自生成内容 | 仍依赖的主要锚点 | 改进器是否自主变化 |
|---|---|---|---|
| Self-Instruct | 指令及回答 | 种子任务、过滤规则、预训练 | 通常否 |
| STaR | 推理轨迹 | 题目与正确答案 | 否 |
| ReST / ReST-EM | 候选输出、成功解 | 奖励或二值验证、任务集 | 否 |
| SPIN | 对照回答 | 原有人工示范分布 | 否 |
| Self-Rewarding | 回答、评价与偏好 | 初始化与评价协议 | 裁判能力可变，外层训练规则仍固定 |
| Self-Taught Evaluators | 评价训练数据 | 初始模型、指令与构造规则 | 裁判参数可变，训练规则仍固定 |
| Quiet-STaR / Toolformer | 思考 / 工具轨迹 | 文本预测目标 / 工具环境 | 否 |

表格是对上列原文机制的综合归纳。下一步是让题目来源也变化，见 [05 自课程](05_curricula.md)。
