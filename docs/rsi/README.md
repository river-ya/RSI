# 大模型与智能体的递归自我改进：论文地图与科研入门

检索核对日期：2026-11-09。RSI 指 Recursive Self-Improvement（递归自我改进）。

这套笔记围绕一个问题组织：**一个系统的能力提升，能否改善它产生下一次能力提升的机制？** 收录 64 篇文献，包含奠基理论、经典方法、近年的代表性系统、反面证据和两篇综述。2025—2026 年的工作称为“近期代表作/前沿”，不预先认定其经典地位。

这是面向科研选题的代表性叙述综述，覆盖主要技术路线；不是穷尽检索，不能把“64 篇”理解为已覆盖全部相关论文的某个比例。论文卡片提供问题、方法、证据边界、关联与研究启发；核心 RSI 系统另有横向比较。研究建议是本笔记的综合判断，不是已经验证的新发现。

## 建议先抓住的结论

1. **自生成不等于自验证。** Self-Instruct 能生成数据，STaR 能生成推理，但质量信号仍决定它们能学到什么。R-Zero 的多数票与 Absolute Zero 的执行反馈也不是同一强度的证据。
2. **系统级改进不要求模型权重改变。** 工具、记忆、流程和代码都能形成持久能力；但是每次重新提示一个固定模型，并不自动意味着改进机制在演化。
3. **元层变化需要单独测量。** STOP、Promptbreeder、SICA、DGM、Hyperagents 值得重点阅读，因为它们触及生成下一代改进的程序或策略；任务分数仍不能完全代替元层能力指标。
4. **验证、预算和迁移是科研的关键。** 固定预算下的独立测试、跨任务迁移、冻结改进器对照，通常比增加一层“反思 agent”更能说明问题。
